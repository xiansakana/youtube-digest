4下一步：启动每日任务

授权和配置都完成后，在项目根目录执行：

docker compose up -d --build
  • 容器默认每天 Asia/Shanghai 12:00 自动运行一次。
  • 想先验证：docker compose run --rm digest python run.py --dry-run --days 3 --limit 3
  • 想立即跑一次真实任务：docker compose run --rm digest python run.py --days 1
  • 日志：docker compose logs -f digest，或查看 data/logs/

控制台只监听 127.0.0.1，不会暴露到公网
